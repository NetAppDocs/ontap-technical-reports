= EDA overview
:icons: font
:imagesdir: ./media

[.lead]
Electronic Design Automation (EDA) workloads combine some of the highest metadata rates, largest file counts, and most complex data lifecycle requirements of any enterprise workload. Understanding what makes EDA unique is essential context for storage architecture decisions.
