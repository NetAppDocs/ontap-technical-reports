= AFX architecture
:icons: font
:imagesdir: ./media

[.lead]
NetApp AFX is a purpose-built high-performance storage platform that runs ONTAP software in a disaggregated architecture. It introduces fundamental changes to how storage resources are managed, deduplication is applied, and capacity is protected — changes that have significant implications for EDA deployments.
