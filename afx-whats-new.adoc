== Latest release: ONTAP 9.19.1RC1

As of May 2026, ONTAP 9.19.1RC1 is the latest release available for NetApp AFX.

=== New features in NetApp AFX

* Global deduplication
* Dynamic storage efficiency
* Advanced readahead
* 32 node support
* 32PB support
* 512 constituent volumes per FlexGroup volume
