New features in NetApp AFX:

* link:afx-performance.html#aggressive-read-ahead[Advanced readahead] (Cross File Sequential Read; also see link:https://docs.netapp.com/us-en/ontap-afx/administer/additional-ontap-svm.html#cross-file-sequential-read[AFX SVM administration^])
