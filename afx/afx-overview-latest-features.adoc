== What's new in the latest release of NetApp ONTAP for AFX?

This section covers the latest updates for NetApp AFX and will be updated for each new release. Check back here periodically for new information, but also check out the version release notes.

Latest release:

ONTAP 9.19.1RC1 (as of May 2026)

New features in NetApp AFX:

* Global deduplication
* Dynamic storage efficiency
* Advanced readahead
* 32 node support
* 32PB support
* 512 constituent volumes per FlexGroup volume
